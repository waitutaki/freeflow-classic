# Media and Documents

Freeflow CMS separates images (Media) from files (Documents). Media is optimized for images and provides thumbnails, while Documents supports any file type and download control.

## Media Manager (images)

The Media Manager is used for images that appear on pages, posts, and in themes.

### Uploading an image

1. Open Media Manager.
2. Click Upload.
3. Choose an image file (JPG, PNG, or WebP).
4. Wait for the upload to complete.

### Using images

- Images can be selected for featured images in Pages and Posts.
- Media Picker dialogs allow you to select existing images without leaving the form.

### Thumbnails

- Thumbnails are generated automatically.
- If an original image is removed, related thumbnails are cleaned by Maintenance tasks.

## Documents (files)

Documents are used for downloads, PDFs, and other non-image files.

### Upload a document

1. Go to Documents.
2. Click Upload.
3. Select a file.
4. Save.

### Download permissions

Download access depends on your role permissions:

- If you do not have download permission, the file will not be available.
- Admins can assign document access to roles.

### Renaming and deleting

- Rename documents from the Documents list.
- Deleting a document removes the file from storage.

## Best practices

- Use meaningful file names to make selection easier.
- Keep image sizes reasonable for faster page loads.
- Use the cleanup tools in Maintenance when storage gets cluttered.
