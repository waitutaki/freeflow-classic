# Permissions and Visibility

Freeflow CMS uses role-based permissions. Your role controls which sections you can see and which actions you can perform.

## What permissions control

Permissions determine access to:

- Admin menu items
- Create and edit forms
- Publish actions
- Media and documents management
- System-level settings

If you do not have permission for a section, it will not appear in the Admin menu. If you try to access the URL directly, you are redirected to the login screen.

## Common permission effects

- Manage Content: allows viewing and editing Pages, Posts, and Categories.
- Publish Content: allows publishing or unpublishing content.
- Manage Media: allows uploading, deleting, or editing images.
- Manage Users: allows viewing and editing user accounts.
- Manage Settings: allows changing system configuration.

## How to request access

If you need access to a section you cannot see:

1. Contact a Super admin.
2. Explain the action you need to perform.
3. The Super admin updates your role permissions.

## Locked indicators

Some items are marked as locked. This means:

- You can view the item, but you cannot change its state.
- The state indicator is visible but not clickable.

This helps you understand what is available without accidentally changing protected items.
