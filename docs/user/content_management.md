# Managing Content

Freeflow CMS organizes content into Pages, Posts, and Categories. Each content type has a list screen, a create/edit form, and standard actions.

## Pages

Pages are standalone content items, typically used for static sections like About, Contact, or Policies.

### Create a page

1. Go to Content -> Pages.
2. Click New in the toolbar.
3. Enter the page title.
4. Enter the main content in the editor.
5. Choose the status (draft or published).
6. Save.

### Edit a page

1. Open Content -> Pages.
2. Click Edit on the page row.
3. Update the fields.
4. Save.

### Publish or unpublish

- Publishing is done through the status field in the form.
- Status indicators in the list show whether a page is published or not.

## Posts

Posts are used for the blog or news sections. They share similar fields to Pages but are designed for chronological lists.

### Create a post

1. Go to Content -> Posts.
2. Click New.
3. Enter the post title and content.
4. Add categories if needed.
5. Set the status.
6. Save.

### Edit a post

1. Open Content -> Posts.
2. Click Edit on the post row.
3. Update fields and Save.

## Categories

Categories help group posts. They can also be used in menus and listings.

### Create a category

1. Go to Content -> Categories.
2. Click New.
3. Enter the category name and optional description.
4. Save.

### Assign categories to posts

1. Edit a post.
2. Select one or more categories.
3. Save.

## Slugs and URLs

Pages and posts generate URL slugs from titles. If you edit the slug, ensure it remains unique to avoid conflicts.

## Featured images

Pages and posts can optionally use a featured image. This image appears in listings and previews. The image is selected from the Media Manager.
