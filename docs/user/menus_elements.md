# Menus and Elements

Menus and Elements control how content appears on the site. Menus define navigation structures, and Elements place content blocks into theme positions.

## Menus

Menus contain menu items which link to pages, posts, categories, or custom URLs.

### Create a menu

1. Go to Menus.
2. Click New.
3. Enter a menu name.
4. Save.

### Add items to a menu

1. Open the menu.
2. Click New item.
3. Choose the target type (page, post, category, or URL).
4. Enter the label and destination.
5. Save.

### Order menu items

Use the Move up or Move down actions to reorder items. The order is reflected on the site.

## Elements

Elements are reusable blocks such as menu displays, page lists, or HTML blocks.

### Create an element

1. Go to Elements.
2. Click New.
3. Choose the element type.
4. Configure the settings.
5. Save.

### Assign an element to a position

1. Edit the element.
2. Choose the theme position from the list.
3. Save.

### Enable or disable an element

Elements have an enabled status. Disabled elements do not render on the site.

## How menus and elements work together

- A Menu element renders a menu in a theme position.
- If a menu changes, all menu elements using it update automatically.
- Elements can be targeted to specific pages or sections depending on configuration.
